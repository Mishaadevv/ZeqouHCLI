# Security policy

## Reporting a vulnerability

Please do not publish API keys, account credentials, or exploit details in a public issue. Until a dedicated private reporting address is configured, use GitHub's private vulnerability reporting for this repository if it is enabled, or contact the maintainer privately through their GitHub profile.

## Sensitive data

Never include provider API keys, local `config.json` files, `.env` files, or saved chat sessions in bug reports or commits. Treat model output and web page content as untrusted input. Review commands and file diffs before approving agent actions.
